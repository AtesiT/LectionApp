Motion Playground Web

Это web-версия исходного MAUI-приложения для запуска на ПК в браузере.

Как запустить (macOS / Linux):
1. Распакуйте архив.
2. В терминале:
   cd MotionPlayground_Web
   chmod +x run_local_server.sh stop-server.sh   # один раз, если «permission denied»
   ./run_local_server.sh
3. Откройте в браузере: http://localhost:8080

Если «порт занят» или сервер не стартует:
   ./stop-server.sh
   ./run_local_server.sh

Если «permission denied»:
   bash run_local_server.sh

Совместная сессия (несколько человек):
1. Запустите сервер на одном компьютере (./run_local_server.sh).
2. В терминале будет адрес для локальной сети, например http://192.168.1.5:8080.
3. При открытии сайта сначала экран входа: имя (обязательно) и «Войти в сессию».
4. До входа приложение заблокировано; после входа доступны анимации и настройки.
5. В блоке «Действия участников» видны смена темы, 2D/3D, анимации и т.д.
6. Сцена синхронизируется у всех подключённых участников.

Остановить сервер:
- Ctrl+C в терминале, где запущен сервер, или: ./stop-server.sh

Если Python не установлен:
- можно открыть index.html напрямую, но 3D-модель в некоторых браузерах может не загрузиться из-за ограничений безопасности;
- лучше установить Python 3 (на macOS обычно уже есть python3) и запускать через run_local_server.sh.
Windows:
1. Установите Python 3 для Windows.
2. Откройте папку MotionPlayground_Web.
3. Запустите start_server.bat
4. Для остановки используйте stop_server.bat
5. Для доступа с другого устройства используйте IP адрес, который покажется в окне сервера.

Обновление: независимые объекты пользователей
---------------------------------------------
В совместной сессии каждый подключившийся управляет своим объектом локально.
Действия других пользователей больше не меняют вашу фигуру, анимацию, скорость, тему или 3D-поворот.
При этом список онлайн-пользователей и лента действий остаются общими.


Обновление: режим ряда моделей
- На сцене отображаются модели всех подключившихся пользователей в одном горизонтальном ряду.
- У каждого участника сохраняется собственная независимая модель: форма, 3D/2D, анимация, скорость и состояние запуска.
- При изменении настроек одним участником обновляется только его карточка в общем ряду, остальные модели не перезаписываются.
