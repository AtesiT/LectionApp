Motion Playground Web 2.0
=========================

Учебная песочница анимаций в браузере: 2D/3D-фигуры, эффекты, погода, виджеты
и совместная сессия для группы. Без сборки и внешних зависимостей:
чистый HTML/CSS/JavaScript (ES-модули) + сервер на стандартной библиотеке Python.

Как запустить (macOS / Linux)
-----------------------------
1. Распакуйте архив.
2. В терминале:
   cd LectionApp
   chmod +x run_local_server.sh stop-server.sh   # один раз, если «permission denied»
   ./run_local_server.sh
3. Откройте в браузере: http://localhost:8080

Если «порт занят» или сервер не стартует:  ./stop-server.sh  затем  ./run_local_server.sh
Если «permission denied»:                  bash run_local_server.sh
Другой порт:                               PORT=9000 python3 room_server.py

Windows
-------
1. Установите Python 3 для Windows (галочка «Add to PATH»).
2. Откройте папку проекта и запустите start_server.bat
3. Для остановки — stop_server.bat
4. Для доступа с телефона/другого ПК используйте адрес, который покажет окно сервера.

Важно: открывать index.html напрямую как файл нельзя — ES-модули и WebSocket
работают только через http://. Всегда запускайте сервер.

Структура проекта
-----------------
index.html            — разметка (один файл, все панели/вкладки/модальные окна)
styles.css            — стили, 8 тем, адаптив, режимы (презентация, PiP, дискотека)
room_server.py        — сервер: статика, комнаты, WebSocket (+ SSE-запасной канал),
                        чат, опросы, доска, роли, прокси внешних API с офлайн-запасом
manifest.webmanifest, sw.js, icons/ — PWA (установка, офлайн-кэш оболочки)
TECH.md               — подробно: какие технологии использованы и на что каждая влияет
js/main.js            — точка входа, порядок инициализации модулей
js/core/              — bus (события), dom (утилиты), store (состояние + undo/redo), i18n (RU/EN),
                        media (ссылки YouTube/Rutube/VK, загрузка на сервер, сжатие картинок, лимиты),
                        gif (собственный кодировщик GIF89a), plugins (API window.__motion + песочница)
js/scene/             — shapes (clip-path фигуры), animations (Web Animations API, траектории),
                        objects (несколько объектов, drag, запись пути), physics, model3d (CSS 3D,
                        кость, кубик Рубика, гироскоп, инерция), webgl (Three.js с CDN, с откатом),
                        effects (canvas-частицы), backgrounds (фон + видео-фон), cursorfx,
                        preview (мини-сцены участников и просмотр чужой сцены),
                        recorder (запись сцены в видео/GIF и экспорт анимации в CSS/HTML)
js/ui/                — panels (все панели), view (полный экран, презентация, PiP, случайная сцена,
                        реестр команд), shortcuts (горячие клавиши), palette (Ctrl+K), toast, commands,
                        peek (просмотр сцены другого участника и копирование её себе),
                        timeline (ключевые кадры: дорожки, интерполяция, воспроизведение)
js/net/               — transport (WS → SSE, автопереподключение), session (вход, комнаты, роли,
                        лента, витрина участников, AFK, уведомления, журнал), chat, polls, cursors,
                        whiteboard (рисование, запись, скриншот, повтор), admin, qr (собственный QR-кодер),
                        rtc (звонок и демонстрация экрана через WebRTC), shared (общая сцена комнаты)
js/features/          — audio (WebAudio-звуки, микрофон-визуализатор), voice (Web Speech API),
                        weather (Open-Meteo → met.no → wttr.in), widgets (часы, Луна, цитаты/факты, курсы, время
                        участников), achievements, easter (пасхалки), quiz, pwa, gestures,
                        games (шахматы и крестики-нолики на двоих, змейка, камень-ножницы-бумага),
                        snake (логика змейки), powder (песочница «Порошок»: 38 элементов и реакции),
                        journal (журнал занятия с сервера: список, копирование, Markdown)
tests/                — smoke.mjs (дымовой тест интерфейса в Node без браузера), minidom.mjs,
                        server_e2e.mjs (сервер), media_test.mjs (ссылки на видео и лимиты медиа),
                        chess_test.py (шахматный движок), powder_test.mjs (песочница),
                        snake_test.mjs (змейка), timeline_test.mjs (ключевые кадры),
                        export_test.mjs (экспорт CSS/HTML), plugins_test.mjs (API плагинов),
                        gif_test.py (GIF читается независимым декодером),
                        qr_roundtrip.py (независимый декодер QR)

Что умеет
---------
Сцена и объекты
- До 12 объектов на сцене: перетаскивание мышью/пальцем, слои, дублирование, «в центр».
- Фигуры: круг, квадрат, треугольник, звезда, сердце, шестиугольник, кольцо, emoji, текст,
  картинка/SVG, видео. Свойства: цвет, размер, прозрачность, тень, свечение, обводка, скругление.
- Медиа в объектах: картинка сжимается до ~30 КБ и уезжает остальным участникам; видео ставится
  ссылкой на YouTube / Rutube / VK (видно всем) либо файлом mp4/webm (до 90 КБ также всем).
- 20 анимаций (пульс, вращение, скольжение, затухание, прыжки, тряска, переворот, качели,
  шатание, желе, сердцебиение, tada, мигание, спираль, зигзаг, орбита, смена цвета,
  морфинг, парение, резина). Любые комбинации, поиск, избранное, клавиши 1–9.
- Траектории: круг, восьмёрка, нарисованный мышью путь. Скорость 0.2–3x.
- Физика: гравитация, отскоки от стен, столкновения, бросок объекта с инерцией.
- Кнопка «Случайно» (R) — случайная сцена. Undo/Redo (Ctrl+Z / Ctrl+Y).

3D
- CSS 3D: куб, пирамида, призма, цилиндр, сфера, додекаэдр, тор, игральная кость, кубик Рубика.
- Вращение мышью с инерцией, зум колёсиком/пинчем, сброс камеры, гироскоп телефона.
- Кость бросается (результат идёт в ленту), кубик Рубика перемешивается/собирается,
  ходы U D L R F B (Shift — обратный ход).
- Режим WebGL: Three.js подгружается с CDN (нужен интернет); без сети — аккуратный откат на CSS 3D.

Оформление и эффекты
- 8 тем, фоны: 10 градиентов, цвет, картинка/видео из файла или по URL, параллакс.
- Видео-фон по ссылке на YouTube, Rutube или VK: вставляется плеером, играет и виден
  всем участникам комнаты. Свой файл mp4/webm до 90 КБ тоже уезжает в комнату,
  файл побольше остаётся локальным фоном (остальные увидят подпись «медиа только у автора»).
- Эффекты на canvas: снег, дождь, листопад, лепестки, светлячки, туман, конфетти, звездопад, матрица.
- Эффекты курсора: шлейф, искры, пузырьки; ripple на кнопках.
- Погода: город или геолокация, прогноз на 5 дней. Источники перебираются по очереди:
  Open-Meteo → api.met.no → wttr.in (и геокодер: Open-Meteo → Nominatim), так что в РФ,
  где часть сервисов недоступна, погода всё равно приходит. Внизу виджета видно, кто ответил.
- Режим «сцена повторяет погоду» — эффект, оттенок и ветер по реальной погоде. Если связи
  нет вообще — показывается последний сохранённый прогноз.

Звук и голос
- Звуки интерфейса на WebAudio (без файлов), громкость, выключение (M).
- Микрофон: объекты пульсируют под звук, внизу сцены эквалайзер.
- Голосовое управление (Chrome/Edge): «старт», «стоп», «быстрее», «синий», «звезда»,
  «снег», «3D», «тема неон», «полный экран» и т. д.

Совместная сессия
- Комнаты с кодом (ссылка ?room=КОД, QR-код для входа с телефона), список активных комнат.
- Роли: первый вошедший — ведущий 👑 (передача роли, исключение, заморозка сцен,
  объявления, очистка ленты/чата, «применить мою сцену всем»). Режим «следовать за ведущим».
- У каждого — собственная независимая сцена; справа витрина мини-сцен всех участников
  (2D и 3D), лайки, реакции-emoji, локальное время участника по его часовому поясу.
- Чат с emoji и индикатором набора текста, лента действий, опросы с живыми результатами,
  живые курсоры участников, статус AFK.
- Общая доска: рисование поверх сцены, а также запись рисования в видео-файл (⏺ Записать),
  скриншот сцены в PNG (📷 Скриншот) и повтор рисунка с теми же паузами (↻ Повторить).
- Витрина участников показывает все их объекты (фигуры, картинки, видео), а по кнопке 👁
  (или щелчку по карточке) открывается крупный просмотр чужой сцены: его фон, видео-фон,
  эффекты и объекты с анимациями. Оттуда же сцену можно «поставить себе» одной кнопкой.
- Транспорт: WebSocket с автопереподключением и индикатором; если WS недоступен —
  Server-Sent Events + POST. Браузерные уведомления о новых участниках/сообщениях.

Новые возможности этой версии
- Таймлайн: у каждого объекта свои дорожки ключевых кадров (X, Y, размер, прозрачность, свечение,
  скругление, цвет). Между ключами значения считаются сами, цвет смешивается плавно. Есть шкала
  времени, перетаскивание ключей мышкой, воспроизведение с зацикливанием.
- Общая сцена: ведущий включает один «холст» на всю комнату — все правят его вместе. Личная сцена
  при этом сохраняется: каждый участник переключается кнопками «Общая / Моя».
- Звонок и демонстрация экрана (WebRTC): видео и звук идут напрямую между браузерами, сервер только
  передаёт служебные сообщения (сигналинг). Есть кнопки микрофона, камеры и показа экрана.
- Серверное хранилище медиа: картинки и видео уезжают в папку uploads/ на сервере — лимит 120 КБ
  на сцену больше не мешает (файл до 25 МБ). Без сервера работает прежний локальный путь.
- Комнаты переживают перезапуск сервера: участники, чат, лента, доска, опросы и игры пишутся
  в data/rooms.json. Плюс «Журнал занятия» — вся история комнаты, копируется и сохраняется в Markdown.
- Запись всей сцены: видео (MediaRecorder) и GIF 4 секунды (свой кодировщик GIF89a, без зависимостей).
  Анимацию объекта можно выгрузить готовым CSS или целым HTML-файлом и вставить к себе на сайт.
- Мини-игры: шахматы и крестики-нолики на двоих (доска одна на всех, ходы проверяет сервер,
  подсвечиваются легальные ходы и шах), а ещё локальные змейка и «камень-ножницы-бумага».
- Песочница «Порошок»: 38 элементов (песок, вода, огонь, лава, кислота, порох, газ, ток, облака…)
  с настоящими реакциями: вода тушит огонь, лава плавит лёд и снег, кислота ест почти всё,
  порох и газ взрываются, растения растут в воде, ток бежит по металлу, пустота стирает соседей.
- API плагинов: window.__motion + песочница. Плагин управляет сценой, объектами, фоном, эффектами,
  таймлайном, чатом; window, document, fetch и eval внутри закрыты. Четыре готовых примера.

Прочее
- Локализация RU/EN (кнопка EN/RU или клавиша L), горячие клавиши (?), командная палитра (Ctrl+K).
- Полный экран (F), режим презентации (P), картинка-в-картинке (Document PiP API, Chrome 116+).
- Виджеты: часы, фаза Луны (считается локально), цитата/факт дня, курсы валют ЦБ РФ и крипто
  (через прокси сервера; без интернета — понятное сообщение/офлайн-набор).
- 52 достижения (в том числе за видео-фон, запись доски и просмотр чужих сцен), квиз по анимациям,
  встроенная справка.
- Пасхалки: код Konami (↑↑↓↓←→←→BA) и 10 кликов по логотипу.
- PWA: устанавливается как приложение, оболочка работает офлайн.
- Мобильная адаптация: свайп по вкладкам, пинч-зум, двойной тап — старт/стоп.
  Проверено на ширине от 320 px (экран 4 дюйма): одноколоночные панели, горизонтальная
  прокрутка вкладок, кнопки не меньше 32 px, поля — 16 px, чтобы iOS не зумила при фокусе.

Проверка без браузера (нужен Node.js 22+)
-----------------------------------------
1. Запустите сервер: python3 room_server.py
2. В другом терминале:
   node tests/smoke.mjs        — интерфейс: index.html загружается в мини-DOM, тест входит в
                                 сессию, кликает по всем панелям (включая новые: таймлайн,
                                 мини-игры, песочница, экспорт, плагины, журнал), подключает
                                 второго участника по WebSocket (181 сценарий)
   node tests/server_e2e.mjs   — сервер: комнаты, роли, чат, опросы, доска, заморозка, игры,
                                 общая сцена, сигналинг звонка, журнал, загрузка файлов,
                                 постоянство комнат, SSE и каскад погоды (78 проверок)
   node tests/media_test.mjs   — ссылки YouTube / Rutube / VK, адреса плееров и лимиты
                                 на передачу медиа между участниками (14 проверок)
   node tests/powder_test.mjs  — песочница «Порошок»: физика, химия, сохранение материи (38)
   node tests/snake_test.mjs   — логика змейки: движение, еда, столкновения (11 проверок)
   node tests/timeline_test.mjs — расчёт значений между ключевыми кадрами (10 проверок)
   node tests/export_test.mjs  — экспорт анимации в CSS и HTML (9 проверок)
   node tests/plugins_test.mjs — API плагинов и песочница: window/document/fetch закрыты (12)
   python3 tests/chess_test.py — шахматный движок сервера: ходы, шахи, мат, превращение (34)
   python3 tests/gif_test.py   — GIF, который собрал наш JS, читается независимым декодером (18)
   python3 tests/qr_roundtrip.py — QR-кодер: независимый декодер читает наши коды обратно

Ограничения
-----------
- WebGL-режим, погода, цитаты и курсы требуют интернета (всё остальное работает офлайн).
- Голосовое управление и Document PiP — только в Chrome/Edge; гироскоп — на телефоне по https
  или localhost (iOS попросит разрешение).
- Медиа: картинки и видео лучше всего загружать на сервер (кнопки в панелях «Объект» и «Сцена») —
  тогда они видны всем без ограничения 120 КБ на сцену. Если сервер недоступен, работает прежний
  путь: сжатые картинки и небольшие файлы уезжают целиком, тяжёлое остаётся у автора (заглушка).
- Видеозвонок (WebRTC) требует камеры/микрофона и работает только по https или на localhost;
  при показе экрана браузер спросит разрешение. Запись сцены в GIF занимает 4 секунды реального
  времени — это время «проигрывается» на сцене, ничего делать не надо.
- Запись доски (MediaRecorder + canvas.captureStream) не работает в старых Safari — там доступны
  скриншот и повтор рисунка.
